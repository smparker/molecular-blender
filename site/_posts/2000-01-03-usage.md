## Install in Blender

1. Download the [Blender add-on ZIP]({{ site.source_link }}/releases/download/{{ site.release_tag }}/molecular_blender.zip) and keep it zipped.
2. In Blender 4.3, open **Edit → Preferences → Add-ons**. Open the menu at the top right, choose **Install from Disk…**, and select the ZIP. In Blender 3.6, use **Install…** in Add-ons.
3. Enable **Molecular Blender** in the add-ons list.

### Try your first orbital

Save the [water sample]({{ site.source_link }}/blob/{{ site.release_tag }}/examples/water-sto-3g.molden) using GitHub’s **Download raw file** button. In Blender, choose **File → Import → Molecular Blender**, select the file, and set **Field** to **Molecular orbital** and **Orbital** to **HOMO**. Confirm the import to see the two signs of the orbital.

Select an atom and press **N** in the 3D Viewport to open the **Molecule** tab. You can add another orbital to the same molecule there.
